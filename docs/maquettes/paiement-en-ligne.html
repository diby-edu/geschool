Comment on est sûr que l’argent est arrivé
1Le retour sur le site ne suffit jamais : n’importe qui peut taper l’adresse de retour.
2Quand PayDunya prévient l’application, celle-ci vérifie la signature du message, puis redemande elle-même à PayDunya le statut et le montant de ce paiement.
3Seulement si PayDunya répond « payé » et que le montant correspond exactement : le paiement est noté, le module prolongé, le reçu émis. Un même paiement n’est jamais compté deux fois.
4Filet de sécurité : si le message de PayDunya se perd, une tâche du worker revérifie les paiements en attente toutes les 15 minutes.
